# 🏎️ Street Racers 2D

Juego de carreras 2D multijugador local inspirado en Traffic Racer.

## Instalación
```bash
pip install -r requirements.txt
```

## Ejecutar
```bash
python main.py
```

## Controles
- **Jugador 1**: W/A/S/D
- **Jugador 2**: Flechas direccionales

## Características
- Modo multijugador local
- Sistema de mejoras y desbloqueos
- Múltiples pistas y condiciones climáticas
- Sistema de monedas y experiencia
